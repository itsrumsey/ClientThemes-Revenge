# ClientThemes-Revenge

Standalone ClientThemes extraction from [aeongdesu/vdplugins](https://github.com/aeongdesu/vdplugins) at `4d1ed7f7d6c9fca5b7ca417bc4b744fecf44de22`.
Original author: sapphire (aeongdesu). The original source credits m4fn3/FreeNitroTheme; that attribution remains intact. Licensed under GPL-3.0; see LICENSE.

This baseline preserves original plugin behavior. Intended compatibility target: Revenge 1b1d297-main, Discord Android 349.9 (349009), React 19.2.3, React Native 0.86.0, RevengeXposed 1.6.3, Android 16 / SDK 36. Device compatibility is unverified.

Build with Node 22: `npm install`, then `npm run build`. Output: `dist/ClientThemes/index.js` and `manifest.json`. The baseline CI checks the unmodified implementation before modernization. Build success does not prove device compatibility.
